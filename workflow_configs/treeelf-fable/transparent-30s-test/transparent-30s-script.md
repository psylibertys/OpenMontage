# 一被看见就变透明的人｜30秒测试版

只要有人认真看向他，他就会变透明。

可衣服不会消失：衬衫、礼貌的笑、合适的反应，都替他坐在那里，被人喜欢。

衣柜越来越满，镜子里的人越来越少。

直到雨夜，透明手腕露在桌面上。

这一次，他没有藏。

对面的人也没有修补，只是安静看着。

那晚他没变回来。

但胸口深处，有一小块影子，第一次允许自己被光照到。
